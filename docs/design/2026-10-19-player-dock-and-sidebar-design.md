# 播放器重构（底部播放条）与侧边栏智能伸缩 · 设计规格

- 状态：已批准（播放器 = A 方案「底部全局播放条 + 可展开大面板」；侧边栏 = 智能伸缩）
- 日期：2026-10-19
- 范围：仅 UI 呈现层。不改播放内核、不改数据层。

## 1. 目标

1. 听书时的播放控制常驻可得，切页不中断、不丢失控制（对齐 Spotify / 喜马拉雅的音乐播放器心智）。
2. 侧边栏在窗口变窄时自动让出空间，手动折叠偏好被记住并优先于自动行为。
3. 消除详情页与朗读页之间重复的进度/音量/倍速控件，统一为一个播放器组件。

## 2. 非目标

- 不新增播放队列、睡眠定时、上一首/下一首「书」级跳转。
- 不改 `playerStore` 的分段合成、预取、错误处理逻辑。
- 不引入虚拟滚动库、动画库。

## 3. 现状问题

- 播放控制散落在两处：`BookDetailPage`（内嵌 `PlayerControls`）与 `ReadPage`（自绘进度/音量/倍速），逻辑重复、样式易漂移。
- 离开详情页即无播放控制，用户只能靠系统媒体键。
- 侧边栏在 `App.tsx` 里写死 `w-52`，无折叠能力，小窗口挤占主区。

## 4. 方案

### 4.1 底部播放条（新组件 `PlayerDock`）

常驻于主区底部，`player.status !== 'idle'` 时出现，空闲时隐藏。

- **折叠态（默认）**：左＝封面占位（书名首字，渐变底）＋书名＋章节名；中＝上一章／播放·暂停／下一章；右＝时间 `当前/总长`＋粗进度条（可点击与拖拽 seek）＋倍速＋音量＋展开按钮。文本朗读源显示「文本朗读」而非书名。
- **展开态（点击展开按钮切换）**：全高面板，含大封面、书名、作者位显示「第 X 章 · Y/Z 段」、大进度条与时间、完整控件组（上一章、后退 15 秒、播放·暂停、前进 15 秒、下一章）、倍速、音量、**当前朗读段落文本**（滚动高亮当前段）。

数据全部来自 `usePlayerStore`：`status / currentTime / duration / segs / index / volume / playbackRate / source`。章节名、书名、上一章/下一章跳转需要 `source.kind === 'book'` 时的书籍上下文——由 `BookDetailPage` 装载书籍时通过新增的轻量 `useNowPlaying`（zustand）注入 `{ bookId, title, chapterIdx, chapterTitle, chapterCount }`；文本模式下为空，播放条降级显示「文本朗读」并隐藏章级跳转。

### 4.2 侧边栏智能伸缩（改 `App.tsx` 侧栏）

- 宽度三态：展开 `w-52`（13rem）／折叠 `w-14`（3.5rem，仅图标）。
- 折叠按钮置于侧栏右缘，点击切换手动状态。
- **自动逻辑**：窗口宽 < 阈值（768px）时自动折叠；≥ 阈值时按用户手动偏好显示。
- **手动优先**：用户一旦手动切换，本次会话记住该偏好并覆盖自动判断；未手动过则跟随自动。
- 折叠时隐藏文字标签、品牌名与底部说明，仅保留图标与激活态播放小圆点；`title` 提示保留可访问性。

### 4.3 组件与文件变更

| 文件 | 变更 |
|------|------|
| `src/components/player/PlayerDock.tsx` | 新增：底部播放条（折叠/展开两态） |
| `src/store/nowPlayingStore.ts` | 新增：轻量 store，书籍上下文（书名/章节） |
| `src/components/player/PlayerControls.tsx` | 保留（朗读页仍需「开始朗读」入口），移除与播放条重复的进度/音量/倍速，只留开始按钮 |
| `src/pages/BookDetailPage.tsx` | 内嵌播放器替换为装载 nowPlaying + 移除重复控件 |
| `src/pages/ReadPage.tsx` | 进度/音量/倍速改由播放条承担，页内保留开始/段落列表 |
| `src/App.tsx` | 侧栏三态伸缩 + 挂载 `PlayerDock` |

### 4.4 数据流

- 播放内核（`playerStore`）不变；`PlayerDock` 与页面仅订阅其状态。
- `bookPlay.playChapter` 不变；`BookDetailPage` 在选书/切章时写 `nowPlayingStore`。
- 倍速/音量改动仍写 `appPrefs` 持久化（沿用 `saveAppPrefs`）。

## 5. 错误处理

- 播放失败：`player.error` 在播放条展开面板内显示红色文案，不打断控制。
- 无书籍上下文（文本模式）：隐藏章级跳转与封面首字，降级显示「文本朗读」。
- `duration <= 0`（首段合成中）：进度条禁用拖拽，时间显示 `--:--`。

## 6. 测试

- 播放器为视觉组件，验证以 `npm run build`（tsc 严格 + noUnused）与 `npm test`（既有 83 用例不回归）为准。
- 侧栏伸缩逻辑（自动/手动优先级）若抽为纯函数 `resolveCollapsed(width, manual, threshold)`，补单元测试覆盖三种优先级组合。
- 浏览器人工核对：折叠/展开播放条、窄窗口自动折叠侧栏、切页不中断播放。

## 7. 交互细节决策

- 展开面板为覆盖层（overlay），不推挤主区布局。
- 进度条拖拽时实时更新 `currentTime`，松手落定 `seek`。
- 播放条出现在主区底部时，主区增加等高 padding 避免内容被遮挡。
